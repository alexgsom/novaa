# Nova Studio 3.0 — відновлений прогрес оновлень 20–24

Основа: **Nova Studio 3.0 Update 19 + Windows MSVC Fix 20**, збережені всі наявні компілятор, VM та команди Studio. **Це вихідні коди, не готовий Windows EXE.**

## Реалізовано в цій збірці

**20 — мінімалістичний UI:** темна графітова палітра, адаптивна робоча область, приховування Explorer та AI, Focus mode (Ctrl+Shift+E), компактні кнопки й мінімарта лише за наявності місця. Докладніше в `NOVA_STUDIO_UPDATE_20_UI_UA.md`.

**21 — редактор:** `Edit → Indent selected lines` (Ctrl+]), `Outdent selected lines` (Ctrl+[), `Clean trailing whitespace...`. Чистка прибирає тільки пробіли й табуляції наприкінці рядків, зберігає CRLF/LF і запитує підтвердження. Відступи діють на цілі вибрані рядки; історія Undo RichEdit зберігається як одна операція заміни. Важливо: це **не AST-форматер** і він не змінює вирази.

**22 — AI:** у базі Update 19 уже існують AI Proof, попередній перегляд змін та багатофайлове погодження. Їх не переписано. Жодне автоматичне прийняття змін не додано; OpenAI API залишено опційним та з явними підтвердженнями. Нову функцію AI Planning не заявлено готовою.

**23 — App Designer:** додані `Center X`, `Center Y`, `Duplicate` у панелі праворуч; центрування враховує габарити форми, дублювання зміщує новий елемент та поважає обмеження у 32 компоненти. Збережено попередні шаблони, генерацію Nova та ручну перевірку змін.

**24 — debug foundation:** команда `nova-native exec program.nbc --trace-steps 50` записує до stderr до 50 кроків байткоду з `pc`, назвою операції, кількістю елементів стека та рівнем викликів. Немає значень змінних чи операндів. Межа 1..10000, трасування вимкнене за замовчуванням. Це **діагностична база**, не графічний покроковий debugger з breakpoints.

## Результати в Linux-середовищі

- C++ CMake build: успішно для нативних Linux-цілей.
- CTest: **9/9 PASS**.
- Studio Python regression tests: **46 tests, 4 SKIP** (разом із новими тестами VM trace).
- Opt-in trace прогнано на реальному `examples/bootstrap/trilingual.nbc`; межу в 10000 перевірено.

## Обмеження і наступні перевірки

1. Відсутні Windows SDK/MSVC/Mingw у цьому середовищі: **Windows GUI, компіляцію Win32 і візуальний результат потрібно перевірити в GitHub Actions на Windows**. Наявність тестів C++ на Linux не підтверджує компіляцію Studio на MSVC.
2. Windows нативний інтерфейс все ще використовує деякі системні Win32 компоненти, зокрема меню. Це **не** повна заміна оболонки на кастомну систему.
3. AI Planning, повний debugger з breakpoints і auto-update залишаються незавершеними; не позначені як реалізовані.
4. Зроби backup або Git commit, потім розпакуй Full у чисту папку або Patch поверх **Update 20 UI**. Для оновлення безпосередньо з Update 19 використовуй Full.
5. Запусти GitHub Actions `Nova Windows x64 Acceptance`; після зеленої збірки перевір відступи, Designer і запуск програми вручну на Windows 10/11.
