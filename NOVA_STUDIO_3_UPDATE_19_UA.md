# Nova Studio 3.0 Preview — Update 19

**Обраний стиль:** збережено попередній стриманий темний інтерфейс Nova Studio Next. Кіберпанк-оформлення **не додається**. Оновлення розвиває наявну робочу програму, не замінює C++ рушій Nova.

## Професійний редактор

- **Номери рядків** у власній панелі зліва від Win32 RichEdit; натисни на номер, щоб перейти до рядка.
- **Мінімарта коду** праворуч від редактора: компактні рядки, виділення поточного рядка та перехід у потрібну ділянку кліком. На вузьких вікнах мінімарта ховається; для швидкодії відображаються перші 12 000 рядків.
- **Поточний рядок** має окреме тло (коли доступний RichEdit), а номер у полі зліва виділяється.
- **Ctrl+Space** — пропозиції ключових слів + функцій, оголошених у відкритому файлі.
- **Ctrl+Shift+O** — швидкий перехід до функції у відкритому файлі; працює з `function`, `функція`, `funkcja`. Не є повноцінним LSP або розбором AST.
- **Ctrl+Shift+F** — перейти до поля пошуку проєкту ліворуч. Пошук нечутливий до регістру, охоплює `.nova`-файли в папці проєкту, подвійний клік відкриває файл на потрібному рядку. Обмежено першими 200 файлами, 128 КіБ на файл та 150 результатами.

## ШІ як помічник для проєкту

1. Відкрий папку Nova через **Project**. Збережи всі зміни у файлах.
2. Введи запит у правій панелі, наприклад: «Додай перевірку порожнього імені в усі відповідні файли».
3. Натисни **AI: propose project changes**. Studio спочатку запропонує **погодити надсилання вихідного коду OpenAI**. Без погодження проєкт не відправляється.
4. ШІ отримує назви й короткий перелік функцій до 120 `.nova`-файлів, а також **повний текст лише обмеженого набору**: до 12 невеликих UTF-8 файлів (до 8,5 КіБ на файл, загалом до 19 КіБ). Ключ не зберігається у файлах.
5. Відповідь повинна мати суворий формат окремих блоків ` ```nova:relative/path.nova ` (повна заміна вмісту кожного наявного файлу). Підтримується максимум **6 файлів за одну пропозицію**. Нові файли та вилучення ще не підтримуються.
6. Перед будь-якою зміною Studio показує **порівняння рядків** через розкривний діалог; натисни Yes, щоб перевірити компіляцію запропонованих файлів у тимчасовій папці. Байт-код **не запускається**.
7. Якщо усі змінені файли скомпілювалися, Studio знову запитає окреме підтвердження для запису. Вихідні файли перевіряються на те, що вони не змінилися з моменту запиту; створюються тимчасові резервні копії та пофайлові підміни з відкатом за можливості.
8. Після успішного застосування перевір зміни через GitHub Desktop перед Commit. **Це не транзакція БД, тому у випадку проблем із диском/файловими блокуваннями перевір `.nova19-backup-*` та `.nova19-stage-*`.**

**Обмеження:** це компіляційна перевірка кожного зміненого файла, **не запуск повного тестового набору**. Імпорти з файлів, що не увійшли до переданого набору, можуть не знайтися у тимчасовій папці. Вбудований ШІ не бачить і не змінює C++/Python/секретні файли. Невеликі обмеження контексту потрібні, щоб керувати витратами, приватністю та ризиком перезапису.

Потрібен `OPENAI_API_KEY` із окремим білінгом OpenAI API. Можна використати попередній скрипт `start_nova_ai.ps1`. Модель визначається змінною `NOVA_AI_MODEL` (типово `gpt-4.1-mini`). Звичайне відкриття, редагування, Run, Build та пошук проєкту **не надсилають даних**.

## App Designer

Відкрий **App Designer** або **File → Visual app designer**:

- **Snap: ON/OFF** — показати/вимкнути сітку 10 пікселів та прив'язку до неї.
- Переміщуй елементи мишею, тягни за маленький маркер у правому нижньому куті, щоб змінювати розмір.
- Вибери елемент і редагуй **X / Y / Width / Height** праворуч. Кнопка **Apply position / size** застосує значення. Текст елемента змінюй через **Apply text**.
- **Login layout / Feedback / Dashboard** — шаблони стартового вікна; заміна поточної форми вимагає підтвердження.
- **Live preview** — показує окреме нативне Windows-вікно з реальними стандартними елементами. Це **тільки візуальний перегляд**, обробники кнопок не запускаються.
- **GENERATE NOVA CODE** створює або оновлює `.nova` лише після підтвердження. Сумісний формат `# NOVA-STUDIO-FORM/1` із попереднім Living UI 17 збережено. Рукописні зміни коду захищено.

## Установлення через GitHub Desktop

1. Рекомендовано зробити коміт / резервну копію поточного робочого проєкту Nova.
2. Розпакуй **Nova_Studio_3_Update_19_Patch.zip**. У корені ZIP одразу лежать `studio/`, `tests/`, `.github/` та інші змінені файли — без додаткової папки.
3. GitHub Desktop → **Repository → Show in Explorer** → скопіюй вміст архіву до кореня `novaa` із заміною файлів.
4. **Commit to main → Push origin**.
5. GitHub → **Actions → Nova Windows x64 Acceptance**. Дочекайся **зеленого статусу всього запуску**.
6. Внизу успішного запуску → **Artifacts → nova-windows-x64**. Розпакуй зовнішній ZIP і внутрішній `Nova-Windows-x64-Beta2.zip`, запусти `Nova/bin/NovaStudio.exe`. Старий .exe сам не оновлюється.

- На Linux: збірка CMake/CTest — **9/9 PASS**; перевірки Studio на Python — **38 PASS, 4 SKIP**. Сам компілятор Nova скомпілював приклад `hello_next.nova`; Trinity EN/UK/PL залишився побайтово еквівалентним.
- **Windows MSVC / GUI Smoke Update 19 ще не перевірені в цьому середовищі**: CI додано нові цілі та контроль елементів, але результат треба підтвердити після Push на GitHub.
- Реальні запити до OpenAI з ключем користувача тут **не запускалися**.
