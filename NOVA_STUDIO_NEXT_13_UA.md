# Nova Studio Next — Preview 1 (Update 13)

Це **реальне оновлення вихідного коду** існуючого `NovaStudio.exe`, а не окремий сайт і не зображення інтерфейсу.

## Що вже реалізовано

- Темний Win32-інтерфейс зі стилізованими кнопками, кольоровою підсвіткою Nova, окремими панелями **PROJECT**, **EDITOR**, **OUTPUT** та **AI ASSISTANT**.
- Провідник проєкту: **Project → виберіть папку**, список `.nova` файлів, подвійне натискання для відкриття. Пошук обмежений 500 файлами та глибиною 8 папок для захисту від зависання.
- Кнопки **Project, Open, Save, Run, Compile, Build EXE, Stop, Quick actions**. `Ctrl+Shift+P` відкриває меню швидких дій. Існуючі `F5`, `F6`, `F7`, `Ctrl+K`, `Ctrl+F`, `Ctrl+H` збережені.
- Панель **AI Assistant**: запитання, пояснення або пошук помилок у **виділеному** фрагменті Nova-коду, копіювання відповіді в буфер обміну. Запит до OpenAI Responses API виконується у фоновому потоці через Windows WinHTTP/HTTPS.
- **Приватність:** без API-ключа AI вимкнений; редагування / відкриття файлів / запуск Nova не відправляють даних у мережу. `Ask AI` надсилає введений текст, `Explain code` / `Fix code` — явно виділений фрагмент (максимум 8000 символів). Записи ключа й файлів до репозиторію немає. Відповідь лише відображається, без автоматичної зміни чи запуску коду.

## Як встановити через GitHub Desktop

1. **Рекомендовано:** завантажте маленький `Nova_Studio_Next_13_Patch.zip` і розпакуйте його.
2. У GitHub Desktop відкрийте **Repository → Show in Explorer**.
3. Скопіюйте **весь вміст** розпакованого патча в корінь `novaa`, підтвердивши заміну файлів.
4. Натисніть **Commit to main → Push origin**.
5. Відкрийте вкладку **Actions** на GitHub і дочекайтеся **зеленого** результату Windows-тестів.
6. Завантажте новий Windows **Artifacts**. Старий `NovaStudio.exe` з попередньої збірки **не оновлюється автоматично**.

## Як увімкнути ШІ

1. Потрібен **власний OpenAI API-ключ** із [OpenAI Platform](https://platform.openai.com/api-keys), **окремий від підписки ChatGPT**. Використання API може бути платним.
2. У папці розпакованої Nova, де є `bin/NovaStudio.exe`, у PowerShell запустіть `./start_nova_ai.ps1` і введіть ключ у приховане поле. Скрипт не зберігає ключ у файл.
3. Введіть запит у правій панелі та натисніть **Ask AI**. Для пояснення або виправлення коду спочатку виділіть потрібні рядки в редакторі та натисніть **Explain code** або **Fix code**.
4. За потреби натисніть **Copy answer** і вставте результат вручну. **Перевіряйте AI-код перед запуском.**

Модель за замовчуванням: `gpt-4.1-mini`; можна задати іншу через змінну середовища `NOVA_AI_MODEL` **до запуску** Nova Studio.

**Без ШІ:** запускайте `bin/NovaStudio.exe` як і раніше — усі локальні інструменти редактора працюють без інтернету.

## Збірка з вихідного коду

У **Visual Studio Developer PowerShell** (MSVC):

```powershell
.\build_windows.ps1 -Compiler MSVC
.\bin\NovaStudio.exe
```

Або збірка CMake із `Visual Studio 17 2022` x64. Новий модуль вимагає лише системні Windows бібліотеки `winhttp` та `ole32` (інші сторонні SDK не потрібні).

## Тести та обмеження

- На Linux перевірено переносимі модулі C++: редакторний текст і парсинг/екранування JSON для AI — **2/2 CTest**.
- Статичні Python-тести перевіряють прив'язки меню, приватність і конфігурацію CI.
- **Не перевірено в цьому середовищі:** компіляція Win32 GUI через MSVC, реальне натискання кнопок у Windows і запит до OpenAI API із живим ключем. Це слід підтвердити GitHub Actions та ручним запуском.
- У Preview 1 ще немає вкладок для багатьох файлів, повного Language Server, інтегрованого Debugger і автоматичного застосування AI-правок. Це наступні етапи.
- AI потребує інтернету, оплаченого/доступного API та правильної моделі. Запити мають обмеження розміру/часу; текст відповіді не виконується автоматично.
