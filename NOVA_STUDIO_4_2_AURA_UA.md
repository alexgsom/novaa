# Nova Studio 4.2 — Aura: візуальне оновлення Windows IDE

## Чому в 4.1 екран виглядав застарілим

На реальному скриншоті Windows-збірки були помітні: кнопка `Open`, що перекривала бренд у верхньому лівому куті; білі системні вкладки на тлі темної теми; обірвані написи `EX`, `AI` в боковій смузі; занадто багато однаково великих кнопок у правій панелі; неузгоджені відступи й фони стандартних Win32-контролів.

## Що реально змінено у `studio/nova_studio.cpp`

1. **Вкладки з власним малюванням**: `tabsSubclass` і `paintTabs` перехоплюють `WM_PAINT`, малюють усю темну область вкладок подвійним буфером замість стандартного світлого фону TabControl. Події перемикання вкладок залишаються нативними.
2. **Кнопки й активні елементи**: повне очищення фону власника, заокруглення, шрифт Segoe UI, наведення і стан натискання; усунуто білі кути стандартної owner-drawn кнопки.
3. **Справжні піктограми навігації**: папка, пошук, AI, режим фокусування й термінал малюються GDI, без залежності від emoji/символьних шрифтів.
4. **Виправлення кнопки `Open`**: більше не висить у координаті (0,0); відкрити файл можна через Menu → File → Open або Ctrl+O.
5. **Спокійна тема Aura**: темний графіт, контрастний текст, один світло-зелений акцент. Статичні заголовки фарбуються пензлем правильного батьківського регіону.
6. **Чистіша композиція**: збалансовані розміри верхніх команд, навігації, редактора, Explorer та консолі; адаптація на вузьких вікнах.
7. **Компактний AI Assistant**: на панелі залишені `Ask AI`, `Explain`, `Fix code`, `Review change` у сітці 2×2. Усі інші дії, зокрема Copy answer, Create Nova app та Propose project changes, збережені в Menu → AI / Command Center.
8. **Опціональна темна тема прокрутки** через підтримуваний Windows-модуль `uxtheme.dll` із перевіркою його наявності.
9. **Тести**: актуалізовано старі source-check перевірки під нову геометрію, додано перевірку subclass вкладок і того, що не з'являється зайва кнопка Open, до `--gui-smoke`.

## Що не змінювали

Мова Nova, self-hosted компілятор, bytecode VM, Nova Forge, Project X-Ray, Quality Gate, Time Machine, AI Proof і App Designer залишилися на базі Nova Studio 4.1. Гарячі клавіші F5/F6/F7, Ctrl+S, Ctrl+O, Ctrl+Shift+P, Ctrl+J та Shift+F5 збережені. Під час зміни оболонки не переписувалися алгоритми компіляції.

## Перевірки

- Linux Release CTest: **10/10 pass**.
- Python source-level тести Studio: **52 виконано, 49 успішно, 3 пропущено**.
- Візуальний браузерний концепт `design/AURA_PREVIEW.html` відрендерено Chromium. Скриншот `design/AURA_PREVIEW.png` створено з **HTML-макета**, не з Windows `.exe`.
- **Windows MSVC компіляція нової 4.2 і візуальна перевірка Win32 GUI НЕ проводилися тут.** Реальна відповідність макета та малі розміри вікон вимагають GitHub Actions і перевірки на Windows.

## Як застосувати патч до репозиторію

1. Розпакуйте `Nova_Studio_4_2_Aura_Patch.zip` у корінь репозиторію Nova Studio 4.1 із заміною файлів.
2. Зробіть Commit і запустіть GitHub Actions → **Nova Windows x64 Acceptance**.
3. Переконайтеся, що успішно завершені `cmake --build`, `ctest` і `--gui-smoke`.
4. Завантажте новий ZIP із Windows Artifact та запустіть **саме цей** `NovaStudio.exe`, а не стару копію 4.1.
5. Перевірте, що: кнопка Open більше не перекриває бренд, вкладки темні, навігація має іконки, а AI не займає половину вікна суцільними кнопками. Змініть розмір вікна, щоб перевірити адаптацію.

## Важлива технічна межа

Win32/GDI дає можливість покращити компонування та малювання, але ще не дорівнює повністю сучасному toolkit на кшталт Qt/WinUI. `AURA_PREVIEW.html` є бажаним візуальним напрямом, не точним скриншотом native-інтерфейсу. Для подальшого pixel-perfect розвитку можна поступово перенести UI-shell на Qt 6, залишивши той самий Nova C++ runtime/VM.
