# Nova Studio Next — Preview 3 / Update 15

Це оновлення **вихідного коду для GitHub**. Windows `.exe` з цього архіву не постачається. Після `Commit → Push origin` потрібно дочекатися зеленої Windows-збірки GitHub Actions і завантажити її Artifact.

## 1. Візуальний конструктор застосунків

У Nova Studio натисніть **App Designer** або виберіть **File → Visual app designer**.

- В окремому вікні з'явиться макет 780 × 520 та стартові `Label`, `Input`, `Button`.
- Кнопки `+ Label`, `+ Input`, `+ Button`, `+ Checkbox`, `+ Textarea` додають компоненти (до 32).
- Натисніть компонент і перетягніть його мишею, щоб змінити розташування.
- Праворуч змініть `Selected widget text → Apply text`, налаштуйте розмір через `Width ±`, `Height ±` та змініть заголовок вікна.
- Натисніть **GENERATE NOVA CODE** та підтвердьте створення **нової незбереженої вкладки**. Перед `Save`, `Run` або `Build EXE` перевірте код.

Конструктор генерує справжні `ui.window`, `ui.label`, `ui.input`, `ui.button`, `ui.place`, `ui.run` та початкові функції натискання кнопок. Зразок: `examples/studio_next/designer_demo15.nova`.

**Поточне обмеження:** редагування існуючого `.nova` у дизайнері, сітка/прив'язка, збереження та завантаження проєкту компонування (layout metadata), візуальний перегляд запущеного GUI відсутні. Дизайнер створює вихідний код; це не drag-and-drop конструктор з двосторонньою синхронізацією.

## 2. Інтерактивний термінал для Run

У нижній панелі Studio є нове поле та кнопка **Send input**. Після **Run (F5)** можна вводити текст і передавати рядок на `stdin` запущеної програми. Комбінація **Ctrl+Enter** відправляє поле без миші. Вивід `stdout/stderr` з'являється під час виконання, а не лише після завершення.

Спробуйте `examples/studio_next/interactive_ask15.nova`, введіть ім'я, наприклад `Оля`, натисніть Send input. Рушій байткоду тепер підтримує `ask()`, `запитай()` та `zapytaj()`, раніше ці виклики не працювали в скомпільованих програмах.

**Обмеження:** це ввід рядків для одного процесу Run, не повноцінна системна оболонка PowerShell. Результат у нижній панелі обмежений 1 МіБ. Поле введення активне тільки поки запущена програма готова його прийняти; під час попередньої компіляції вводити текст не потрібно.

## 3. AI → Create Nova app (перший режим генерації застосунків)

У правій AI-панелі напишіть, наприклад, `Зроби вікно з полем і кнопкою привітання`, і натисніть **Create Nova app (AI)**. Запит надсилає лише **написаний вами опис**; файли проєкту автоматично не надсилаються. ШІ проситься відповісти одним блоком ` ```nova `. Після отримання відповіді можна підтвердити створення нової **незбереженої** вкладки з кодом. ШІ нічого не запускає, не записує й не публікує автоматично.

Потрібен ваш `OPENAI_API_KEY` та окремий доступ до платного OpenAI API, як і в Preview 1/2. Результати ШІ можуть містити помилки: перевіряйте їх перед запуском.

**Обмеження:** це чернетка **одного `.nova`-файла**, а не автономне створення багатофайлового проєкту. Мережеве підключення й практичне генерування ШІ на Windows ще не підтверджені локальними тестами.

## 4. Як встановити через GitHub Desktop

1. Розпакуйте `Nova_Studio_Next_15_Patch.zip`.
2. У GitHub Desktop → `Repository → Show in Explorer` відкрийте локальний `novaa`.
3. Скопіюйте **вміст** патча в корінь `novaa`; підтвердьте заміну файлів і збережіть нові папки `studio`, `tests`, `examples`.
4. У GitHub Desktop виберіть `Commit to main → Push origin`.
5. У GitHub → Actions перевірте успіх `Nova Windows x64 Acceptance`; завантажте свіжий Artifact і запустіть новий `NovaStudio.exe`.

## Перевірки та межі підтвердження

- Локальний Linux CMake/CTest: **4/4 PASS**.
- Python-тести Nova Studio: **32/32 PASS**.
- Нативний рушій C++17: **збірка PASS**.
- Згенерований приклад вікна: **Nova self-hosted compiler PASS**, перевірені виклики `ui.window`, `ui.button` та 3×`ui.place`.
- Інтерактивний `ask`: **скомпільований байткод + UTF-8 stdin PASS**.
- Реальний Windows GUI, Win32 callback дизайнера, `CreatePipe`/ввід з IDE, OpenAI API: **потребують перевірки на Windows у GitHub Actions**.

Оновлення №15 не слід називати стабільним релізом до успішної Windows-збірки і ручного запуску на Windows.
