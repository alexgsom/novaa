# Nova Studio — Update 20: мінімалістичний адаптивний інтерфейс

Основа: **Nova Studio 3.0 Preview / Update 19 + Windows MSVC Fix 20**. Це вихідні коди, а не готовий Windows EXE.

## Що оновлено

- Стриманіша темна палітра: нейтральний графіт, помірний синій акцент, кращий контраст тексту.
- Компактніша головна панель, спрощені ширини кнопок; кнопки, які не поміщаються, не перекривають одна одну (усі команди залишаються в меню / гарячих клавішах).
- Адаптивна робоча область: проєктна панель відображається від ширини 1020 px, AI-панель — від 1280 px; при меншій ширині центр отримує додатковий простір.
- **View → Project sidebar / AI sidebar** — незалежне ручне ввімкнення чи вимкнення панелей; при вузькому вікні вони приховуються автоматично.
- **View → Focus mode** (`Ctrl+Shift+E`) — приховує обидві бічні панелі, щоб зосередитися на коді. Повторне натискання відновлює вибрані панелі (за наявності місця).
- Мінікарта коду не займає місце, якщо редактор надто вузький.
- Усі наявні Run, Compile, Build, AI Proof, Multi-file AI, App Designer та Trinity залишилися у кодовій базі.

## Перевірки

- Python: `python -m unittest discover -s tests -p 'test_studio*.py' -q` — 43 tests OK, 4 skipped.
- C++ Linux CMake: усі 9 тестів Studio пройшли (CTest).
- **Win32 UI і MSVC збірка не перевірені в цьому середовищі** — після коміту запустіть Windows GitHub Actions та GUI smoke.

## Як використати

1. Зробіть commit або резервну копію поточного репозиторію.
2. Розпакуйте `Nova_Studio_Update_20_UI_Full.zip` до кореня репозиторію або використайте окремий Patch ZIP.
3. Зробіть commit і push.
4. У GitHub Actions запустіть `Nova Windows x64 Acceptance` та перевірте Windows збірку.
5. Завантажте новий Windows artifact лише після успішного CI. Сам архів не містить готового `.exe`.

**Статус пунктів 20–24:** точний перелік функціональних ідей із переповненого чату не відновився. Цей архів містить лише підтверджений UI-апдейт; невідомі функції 21–24 не позначені як виконані.
