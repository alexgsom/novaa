# Nova Studio Next Preview 1 — Update 13

**Тип релізу:** вихідний код / інтеграційна Preview (Windows EXE не включено).

### Додано

- Нова темна оболонка Nova Studio для Windows: стилізована панель, навігатор папки проєкту, центральний редактор і консоль, права панель AI Assistant, рядок стану.
- Quick actions: меню швидких команд `Ctrl+Shift+P`.
- Пошук `.nova` файлів у вибраній папці, подвійне натискання для відкриття.
- Опційний OpenAI API-клієнт WinHTTP: Ask, Explain selection, Fix selection, Copy answer. Використовується **Responses API**; ключ із змінної середовища `OPENAI_API_KEY`.
- Нові модулі `studio/nova_ai.hpp`, `studio/nova_ai_win.hpp`, переносимі C++-тести JSON/Unicode і перевірки джерел CI.
- Приклад `examples/studio_next/hello_next.nova`.
- `start_nova_ai.ps1` з прихованим введенням API-ключа, без запису ключа в файли.

### Збережено

- Збірку й запуск Nova `F5`, компіляцію `F6`, Build EXE `F7`, Stop, коментування `Ctrl+K`, Open/Save, Unicode-підсвічування та самописний компілятор Nova.

### Приватність і безпека

- AI вимкнений, якщо `OPENAI_API_KEY` відсутній.
- Без явної команди Ask/Explain/Fix жоден файл чи код не надсилається у мережу.
- Explain/Fix надсилають лише вибране користувачем джерело (до 8000 символів).
- Відповідь AI не виконується і не змінює файли без ручної дії користувача.
- Для запитів потрібен інтернет та власний платний або доступний OpenAI API-акаунт; підписка ChatGPT не є автоматичним API-ключем.

### Статус перевірок

- Linux: C++17 Nova runtime збирається через CMake.
- CMake/CTest: 2/2 перевірки портативних модулів пройшли.
- Python Studio regression/Next source tests: 19/19 пройшли.
- **Windows Win32/MSVC, ручний інтерфейс і живий API-запит ще не перевірено**. CI додано, але зелений статус наступного запуску GitHub потрібний.
