# Nova Studio Next — Updates 16 + 17 + 18

Це три нові **Preview-функції** в одній версії. Усі попередні можливості Update 15 збережено.

## 16: Trinity (три мовні представлення)

1. Відкрий `.nova` у редакторі.
2. Меню **Edit → Trinity → English / Українська / Polski** або **Quick actions**.
3. Отримаєш **нову незбережену вкладку** з перекладеними ключовими словами.
4. Порівняй код, протестуй його та збережи окремо за бажанням.

Зберігаються імена змінних, відступи, рядкові константи, коментарі, назви полів і CRLF. Це лексична проєкція відомих ключових слів, а **не повноцінна AST-трансформація кожної конструкції мови**. Поки що редагування двох представлень не синхронізується в реальному часі.

Три приклади в `examples/studio_next/trinity16_{en,uk,pl}.nova` перевірено на однаковий байткод.

## 17: Living UI (повернення у візуальний дизайнер)

1. Відкрий **File → Visual app designer** і створи форму.
2. Натисни **GENERATE NOVA CODE**. Отримаєш нову вкладку з `.nova` і коментарями `# NOVA-STUDIO-FORM/1`.
3. Можна зберегти цей файл як звичайну програму Nova.
4. Для повторного редагування відкрий цей файл і вибери **File → Edit saved designer form**.
5. Пересунь кнопки або зміни їхні тексти. Після підтвердження зміни повернуться у **поточну** вкладку (поки не зберігаються на диск).

Якщо код мінявся вручну після генерації (включно з callback), дизайнер **не перезапише його**: імпорт вимагає точного збігу з останнім канонічним експортом. Це безпечний round-trip MVP, а не довільне двостороннє редагування C++/Nova та не hot reload запущеної програми.

## 18: AI Proof (спершу перевірка, потім застосування)

1. Виділи фрагмент коду Nova, натисни **AI → Fix selected code**. Потрібен власний `OPENAI_API_KEY`.
2. Натисни **AI Proof: Verify / Apply**.
3. Переглянь різницю **BEFORE / AFTER** і дозволь перевірку.
4. Studio запише **повну запропоновану програму** у тимчасовий `.nova`, запустить **тільки компілятор** у фоні й видалить тимчасові файли.
5. Якщо компіляція успішна, з’явиться ще одне вікно підтвердження. Тоді зміна застосовується в редакторі, але **не зберігається на диск** до Ctrl+S.

Якщо компілятор поверне помилку, документ зміниться під час перевірки або ти відмовишся, виправлення **не буде застосовано**. Натискання Stop зупиняє перевірку.

**Обмеження безпеки:** «успішна компіляція» означає лише проходження компілятора; тести проєкту, інструменти статичного аналізу й виконання запропонованого застосунку не проводяться. Тимчасова папка не є повноцінною ОС-пісочницею. Мета Preview — перевіряти зміни перед застосуванням, не роблячи неправдивих тверджень про математичні докази правильності.

## Перевірка

- Linux CMake/CTest: 7/7 нативних тестів (після інтеграції).
- Trinity: 3 мовні приклади успішно запускалися та дали однаковий байткод.
- Windows GUI: **потрібен новий успішний запуск GitHub Actions**.
- Реальні запити до OpenAI: **не виконувалися** (ключ не постачається з Nova).

## Встановлення

Розпакуй `Nova_Updates_16_17_18_Patch.zip` у клон репозиторію через GitHub Desktop, виконай Commit → Push і перевір Windows workflow. Оновлену програму треба завантажити з Windows Artifact, старий `.exe` автоматично не змінюється.
