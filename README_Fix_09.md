# Nova Windows CMake/Text Fix 09

Помилка C2196 у `studio/studio_text.hpp`: різні польські символи у UTF-8 починалися з однакових байтів `0xC4` / `0xC5`; MSVC для тесту не мав прапорця `/utf-8`.

Зміни:
- `CMakeLists.txt`: додано `/utf-8` для `nova-studio-text-tests` (і `/W4 /EHsc` як для решти MSVC-цілей).
- `studio/studio_text.hpp`: польські літери в `case` записані як Unicode escape (`\u0104` тощо), що не залежить від кодування вихідного файлу.

Заміни **обидва** файли у корені репозиторію та у `studio/` відповідно. Коміт запустить нову перевірку.

`ctest` написав «Not Run» не через відсутність тестів, а тому що виконуваний файл не створився після помилки компіляції.

Компіляцію і тести перевірено на Linux. Для остаточної перевірки MSVC потрібен новий запуск GitHub Actions.
