# Nova Studio Next — Preview 2 / Update 14

## Що нового

1. **Справжні вкладки документів** — до 32 файлів `.nova`, зберігаються окремі тексти та стан змін. Наявний файл повторно відкривається у своїй вкладці; кожен незбережений файл перевіряється перед закриттям програми.
2. **Розумне редагування** — `Ctrl+Space` показує меню ключових слів англійською, українською й польською; Enter у RichEdit автоматично додає відступ (4 пробіли після початку блоку). У звичайному Windows Edit auto-indent недоступний.
3. **Problems** — повідомлення компілятора формату `error (line N)` / `warning (line N)` збираються у список. Подвійне натискання відкриває вкладку, яка компілювалася, та ставить курсор на потрібний рядок. Інші формати діагностики поки можуть не визначатися.
4. **AI Preview / Apply** — тільки після кнопки **Fix code** та отримання відповіді з одним блоком ```` ```nova ````. Показує оригінал і пропозицію та обов'язково запитує підтвердження. Якщо документ змінився після запиту, застосування блокується. Великі фрагменти понад 1400 символів не застосовуються автоматично: скопіюйте їх для ручної перевірки. **AI ніколи не змінює файл на диску без Save**.
5. **Оновлена навігація**: `Ctrl+N` нова вкладка, `Ctrl+O` відкрити, `Ctrl+S` зберегти, `Ctrl+Tab` наступна вкладка, `Ctrl+W` закрити вкладку, `Ctrl+Space` автодоповнення, `Ctrl+Shift+P` швидкі дії.

## Як перевірити

- Відкрийте `examples/studio_next/while_demo14.nova`, відкрийте інший `.nova`, змініть текст у першому та перемикайтеся за `Ctrl+Tab`.
- Наберіть `wh` і натисніть `Ctrl+Space`, оберіть `while`. Enter після `while ...` має створити новий рядок із відступом.
- Для Problems запустіть компіляцію файлу з синтаксичною помилкою, де виводиться `line N`, і двічі натисніть на проблему.
- Для AI: виділіть код, натисніть **Fix code**, потім **Preview / Apply AI fix**. Перед застосуванням перечитайте запропоноване виправлення. Це потребує `OPENAI_API_KEY` та може оплачуватися за тарифами API. Звичайне редагування файлів нічого в мережу не відправляє.

## Тестування

- Linux CMake/CTest перевіряє переносимі C++-компоненти без Windows SDK.
- GitHub Actions на Windows має зібрати `NovaStudio.exe`, виконати `--self-test` та `--gui-smoke` і повний набір тестів. До зеленого Windows workflow підтримка нового інтерфейсу **не підтверджена**.
- У Preview 2 кожне перемикання вкладки заново завантажує текст у RichEdit, тому **окрема історія Undo на кожній вкладці поки не зберігається**. Збережений та незбережений вміст при цьому має залишатися у вкладці.
- AI не є автономним агентом; він не читає проєкт без явної команди та не виконує запропонований код.
