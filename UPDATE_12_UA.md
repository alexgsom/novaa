# Nova Update 12 — цикл while та оновлення Nova Studio

## Що нового

### Мова Nova

Цикл з умовою можна писати англійською, українською та польською:

```nova
let i = 1
поки i <= 5
    show i
    i = i + 1
кінець
```

Варіанти першого ключового слова: `while`, `поки`, `dopóki`.
Цикл підтримує `break`/`перерви`/`przerwij` і `continue`/`продовж`/`kontynuuj`.
Умова повторно перевіряється на кожній ітерації. Нескінченні цикли припиняються
після досягнення налаштованого обмеження кроків `--max-steps`.

Зміни виконані **як у C++-інтерпретаторі, так і в компіляторі, написаному Nova**.
Включено оновлений `compiler/novac_selfhost.nbc`.

### Nova Studio

- Панель кнопок у верхній частині вікна: **Save**, **Run**, **Compile**, **Build EXE**, **Stop**.
- Меню **Edit → Toggle comment**, клавіші **Ctrl+K**: додає/прибирає `#` для поточного
  рядка або виділених рядків. Відступи та Windows-завершення рядків CRLF зберігаються.
- Підсвічування розпізнає `while`, `поки`, `dopóki`; покращене розпізнавання
  польських літер на зразок `ó` в ідентифікаторах і ключових словах.

## Встановлення через GitHub Desktop

1. Відкрий GitHub Desktop → репозиторій `novaa` → **Fetch origin / Pull origin**, якщо потрібно.
2. Відкрий **Repository → Show in Explorer**.
3. Розпакуй `Nova_Update_12_Patch.zip` і скопіюй усі папки/файли з нього у
   відкриту папку `novaa`, **зберігаючи вкладеність**. Підтвердь заміну.
4. Повернись у GitHub Desktop → **Commit to main** → **Push origin**.
5. Відкрий GitHub → **Actions**, перевір новий запуск Windows acceptance.
6. Завантаж новий Windows Artifact і розпакуй його. Старий EXE автоматично не оновиться.

**Важливо:** не копіюй тільки `NovaStudio.exe` зі старої збірки: для нового `while`
потрібні оновлені `bin/nova-native.exe` та `compiler/novac_selfhost.nbc` у комплекті.

Повний ZIP містить ту саму структуру без зайвої зовнішньої папки.
Використовуй **маленький патч**, якщо поточний репозиторій уже успішно збирається.

## Перевірка

Перевірені на Linux: збірка C++-рушія; 6 нових тестів `while` для інтерпретатора й
байткоду; 12 тестів самохостингу; 8 тестів текстових функцій Studio; 7 тестів Studio;
26 тестів native04; CMake/CTest для текстових функцій; побайтове співпадіння stage1/stage2 компілятора.
Інші старі довгі тести пакування в локальному середовищі не завершилися; **повний
Windows CI та кнопки в реальному вікні Windows потрібно перевірити в GitHub Actions**.
